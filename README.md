# BenFlow-96-web-project
## Project 2 - HTML Foundation Page

### Description
This project is a personal webpage about my interest in filmmaking. It includes information about my passion for video editing, favorite movies, and the filmmaking process.

### What I Learned
I learned how to structure a webpage using HTML, including adding images, links, tables, and navigation between pages. I also practiced using inline styling without CSS.

### Challenges
One challenge I faced was organizing the layout using only HTML without CSS. It was also tricky making sure all links and pages connected correctly.
